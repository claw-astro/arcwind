# Code of Conduct

arcwind adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: we want taking part in arcwind to be a welcoming, harassment-free
experience for everyone, whatever their background, identity, career stage or
level of experience. Be respectful and constructive in issues, pull requests
and reviews; critique ideas and code, not people. Harassment, insults and
personal attacks are not tolerated.

## Scope

This code applies in all project spaces (the issue tracker, pull requests,
discussions and any other project channel) and when representing the project
elsewhere.

## Reporting

Report unacceptable behavior privately to the maintainer, Charles J. Law, at the
email address on the maintainer's GitHub profile or University of Minnesota
directory listing. Reports are handled confidentially. The maintainer reviews
each report and responds in line with the enforcement guidelines of the
Contributor Covenant, which range from a private warning to a permanent ban from
the project's spaces.
