# Support

arcwind is research software maintained by Charles J. Law (University of
Minnesota). Support is provided on a best-effort basis.

## Getting help

- **Documentation first:** the [documentation](https://claw-astro.github.io/arcwind/)
  covers installation, the analysis step by step, every fitting option, the
  configuration reference, worked tutorials (including synthetic cubes) and an
  FAQ.
- **Questions, bugs and feature requests:** open an issue on the
  [GitHub issue tracker](https://github.com/claw-astro/arcwind/issues). Please
  use the issue tracker rather than private email, so that answers are public
  and help other users. See [CONTRIBUTING.md](CONTRIBUTING.md) for what to
  include in a bug report.

## What to expect

- The maintainer aims to respond to new issues within two weeks; response times
  can be longer during observing runs, travel or busy teaching periods.
- Bugs that give wrong results take priority over new features.
- Fixes go into the latest release; older versions are not patched.
- Supported Python versions are those tested in continuous integration
  (currently 3.8 to 3.13).

## Scope

Help is offered for using arcwind: installing it, configuring and running fits,
reading its outputs and errors. Help with preparing or imaging the data
themselves (calibration, imaging in CASA, and so on) or with interpreting a
particular source is outside its scope, though questions about whether arcwind
suits your data are welcome.

## Reporting a security problem

arcwind runs locally and handles no credentials, but if you find a problem that
should not be reported publicly, use GitHub's private vulnerability reporting
(the "Security" tab of the repository) instead of a public issue.
